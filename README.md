# TimeBot Jr. releases

Installers and the update feed for TimeBot Jr., Stenhouse Consulting's app for logging time to ConnectWise.
No source code lives here.

- Mac: `TimeBot-Jr-<version>.zip` on each release. Signed with Developer ID and notarized by Apple.
  The app updates itself from `appcast.xml` in this repo (Sparkle), and every update is checked
  against a signing key only Henry holds.
- You need your own ConnectWise login and API keys at Stenhouse to use it.
